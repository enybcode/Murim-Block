# Murimblock

Technical foundation for the Murimblock Minecraft mod.

## Development environment

- Minecraft 1.21.1
- NeoForge 21.1.248
- Java 21
- Gradle Wrapper 9.2.1

## Common tasks

```powershell
.\gradlew.bat runClient
.\gradlew.bat build
```

No Murimblock gameplay systems are implemented at this stage.
