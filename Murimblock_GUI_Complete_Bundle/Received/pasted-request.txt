Les images de référence ont été générées par IA.

Elles contiennent donc plusieurs petites imperfections :

* traits irréguliers ;
* éléments légèrement asymétriques ;
* pixels parasites ;
* bordures floues ;
* différences d'épaisseur ;
* petits halos ;
* éléments parfois mal centrés ;
* décorations collées entre elles ;
* différences de style entre certains boutons.

Je ne veux pas que tu découpes simplement ces images.

Je veux que tu **reconstruises les éléments proprement**.

Les références doivent servir de modèle visuel, pas de matériau final à découper.

# Direction artistique

Le style Murimblock doit être :

* très épuré ;
* élégant ;
* lisible ;
* légèrement traditionnel ;
* inspiré Murim / Wuxia / Xianxia ;
* compatible visuellement avec Minecraft.

Palette principale :

* noir ;
* blanc cassé ;
* gris ;
* encre ;
* parchemin très clair.

Couleurs secondaires utilisées avec modération :

* bleu pour le Qi ;
* violet éventuellement ;
* or pour une sélection importante.

Je ne veux PAS une interface RPG remplie de couleurs et d'informations.

Le design doit respirer.

Utiliser beaucoup d'espace vide.

---

# Style graphique

Utiliser principalement :

* traits fins ;
* cadres simples ;
* petits losanges ;
* séparateurs élégants ;
* formes rectangulaires ;
* décorations discrètes.

Décorations Murim possibles :

* bambou ;
* montagnes à l'encre ;
* cercle de pinceau ;
* parchemin ;
* livre martial ;
* lotus ;
* symbole de cultivation.

Les décorations ne doivent jamais rendre l'interface difficile à lire.

---

# Règle importante de Murimblock

La seule statistique principale visible dans Murimblock est :

**Qi**

Il ne doit pas y avoir :

* Force ;
* Dextérité ;
* Intelligence ;
* Vitalité ;
* Défense ;
* points de statistiques.

Le Royaume de cultivation peut également être affiché.

Exemple :

`Qi Refining III`

Mais ce n'est pas une statistique à distribuer.

```text
--------------------------------------------------

```

La zone joueur doit être prévue pour accueillir plus tard le modèle 3D du joueur Minecraft.

Créer seulement l'espace prévu pour lui.

# GUI 2 — Techniques

C'est le GUI le plus important.

Je veux conserver cette idée générale :

```text
--------------------------------------------------------------
|                         TECHNIQUES                     [X] |
--------------------------------------------------------------
|                |                          |                |
| TOMES          | TECHNIQUES               | DÉTAILS        |
|                |                          |                |
| > Tome Épée I  |       [ Technique 1 ]    | Slash frontal  |
|                |                          |                |
|   Tome Épée II |       [ Technique 2 ]    | Description    |
|                |                          |                |
|   ???          |       [ Technique 3 ]    | Coût : 25 Qi   |
|                |                          |                |
|   ???          |       [ Technique 4 ]    | CD : 4 sec     |
|                |                          |                |
|                |                          | [ ÉQUIPER ]    |
--------------------------------------------------------------
```

Je veux :

* une colonne pour les tomes ;
* une zone centrale pour les techniques ;
* une zone de détails ;
* beaucoup d'espace ;
* peu de texte ;
* une hiérarchie visuelle très claire.

---

# Tomes

Préparer plusieurs états visuels.

## Tome normal

Livre simple.

## Tome sélectionné

Contour légèrement doré ou accent discret.

## Tome verrouillé

Livre assombri ou cadenas.

## Tome inconnu

Afficher éventuellement :

`???`

ou une icône de point d'interrogation.

│            │
└────────────┘
