Murimblock GUI Assets

This folder contains PNG assets sliced from the supplied GUI atlas.

Recommended use:
- Keep PNG transparency enabled.
- Use gui_blank_main.png as a generic full-screen base.
- Use gui_profile_template.png as the profile/character layout reference.
- Tabs, buttons, Qi bars, skill slots, decorative elements and icons are separate files.
- assets_manifest.json contains each asset's source coordinates and exported dimensions.
- murimblock_gui_atlas_original.png is the untouched reference atlas.

Important:
These assets were cropped from the concept artwork. For Minecraft/NeoForge, Codex can load them as textures and scale/position them in Screen rendering code.
