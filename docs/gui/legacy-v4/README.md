# Historical V4 Assets

These five PNGs belong to the historical `../tab-layout-demo.html` reference.
They are preserved here for comparison, not loaded by Minecraft or shipped in
the mod jar. The current GUI is Clear Manuscript, documented in `../TAB_LAYOUT.md`.

Do not move these reference images back into `src/main/resources`. The runtime
draws native pixel geometry and uses only the manuscript font and compact Qi sprite.
